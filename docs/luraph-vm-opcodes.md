# Luraph VM — opcode space

Interpreter core: handler `po` — **12,624 tokens** (largest of 147 handlers)

## Architecture, read off the core

```
e[n]        -> opcode fetch        (e = bytecode stream, n = pc)
E = e[n]    -> the opcode value
c[n] s[n] i[n] -> operand streams   (parallel arrays, same pc)
D[...]      -> register file (the VM stack frame)
Z[y + d]    -> constants / upvalue table, y = frame base
J[26]       -> arg-packing helper (builds a call argument list)
J[60]       -> return-adjust helper
J[4]        -> closure/thread spawn used for the main loop
```

Opcode dispatch is a **binary-search comparison tree** on `E` — 198 comparisons,
198 distinct boundary constants. That set *is* the opcode space.
